From sample to screening result

An auditable water-quality screening exercise with explicit units, reporting limits and uncertainty.

Synthetic demonstration. All sites, measurements and geological units are fictional.

These example values are chosen for teaching and are not regulatory criteria. Changing them explores the decision rule.

Hollow bars show reporting limits for non-detects, not measured concentrations.

How it works

Detected values above the selected reference are flagged. A result exactly equal to the reference is classified as at or below it.

For a non-detect reported as < L, the concentration lies below reporting limit L. If L is at or below the reference, the result is below the reference. If L exceeds it, the comparison is indeterminate.

No values are substituted for non-detects. Units must match; nitrate is expressed as NO₃, not as nitrogen. This is a screening demonstration, not a compliance determination or a statement about drinking-water safety.
